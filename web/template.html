What's in the frame?

A small convolutional network, written and trained in C++ with LibTorch on two CPU cores, sorts 32-pixel photos into ten kinds: airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck. Below is a contact sheet of test photos it never trained on, marked up the way a photographer would: circled when it's right, crossed out with its wrong guess when it isn't. Click any frame to look closer, or develop one of your own.

Behind a server

The same model runs in a small C++ HTTP server. Send it any PNG or JPEG:

./build/serve --port 8080
curl --data-binary @cat.jpg \
  localhost:8080/classify
